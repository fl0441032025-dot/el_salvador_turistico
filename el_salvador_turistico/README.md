# El Salvador Turístico

Sitio web académico sencillo desarrollado con HTML5, CSS3 y JavaScript puro.

## Archivos
- `index.html`: estructura del sitio y sus cuatro secciones principales.
- `styles.css`: colores, distribución y diseño adaptable.
- `script.js`: menú móvil y año automático del pie de página.

## Cómo ejecutar
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador. También puedes usar Live Server.

No requiere dependencias. Las imágenes se cargan desde Unsplash, por lo que necesitan conexión a internet.

## Funcionalidad JavaScript
El botón de menú abre y cierra la navegación en pantallas pequeñas. Al seleccionar un enlace, el menú se cierra. El año del footer se actualiza automáticamente.

## Commits solicitados
Para demostrar el desarrollo progresivo, realiza cada commit al terminar esa sección, antes de continuar:

1. `feat: crear identidad y logo del sitio`
2. `feat: agregar barra de navegacion`
3. `feat: maquetar seccion principal de destinos`
4. `feat: agregar pie de pagina`
